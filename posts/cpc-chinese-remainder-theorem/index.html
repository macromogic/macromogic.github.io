模数不两两互质的情形

方法一：转化为模数互质

先提出以下引理1：

引理 1 方程组有解的充要条件是 ∀i,j∈{1,2,…,n},i≠j, \forall i, j \in \{1, 2, \dots, n\}, i \neq j,\ ∀i,j∈{1,2,…,n},i=j,  gcd⁡(mi,mj)∣(bi−bj)\gcd(m_i, m_j) \mid (b_i-b_j)gcd(mi​,mj​)∣(bi​−bj​)。

证明

考虑将

{x≡a1(modm1)x≡a2(modm2)\begin{cases} x \equiv a_1 \pmod {m_1}\\ x \equiv a_2 \pmod {m_2} \end{cases}{x≡a1​(modm1​)x≡a2​(modm2​)​

转化为不定方程组：

{x=pm1+a1x=qm2+a2\begin{cases} x = pm_1 + a_1\\ x = qm_2 + a_2 \end{cases}{x=pm1​+a1​x=qm2​+a2​​

两式相减得：

pm1−qm2=a1−a2pm_1 - qm_2 = a_1 - a_2pm1​−qm2​=a1​−a2​

若方程有解，由 Bezout 定理知，gcd⁡(mi,mj)∣(ai−aj)\gcd(m_i, m_j) \mid (a_i - a_j)gcd(mi​,mj​)∣(ai​−aj​)，以此类推可证必要性。充分性同理。

引理 2 设 mmm 为正整数，对其质因数分解得 m=∏i=1αpieim = \prod\limits_{i=1}^{\alpha} p_i^{e_i}m=i=1∏α​piei​​，则方程 x≡a(modm)x \equiv a \pmod mx≡a(modm) 等价于方程组

{x≡a(modp1e1)x≡a(modp2e2)⋮x≡a(modpαeα)\begin{cases} x \equiv a \pmod {p_1^{e_1}}\\ x \equiv a \pmod {p_2^{e_2}}\\ \quad \vdots\\ x \equiv a \pmod {p_\alpha^{e_\alpha}} \end{cases}⎩⎨⎧​x≡a(modp1e1​​)x≡a(modp2e2​​)⋮x≡a(modpαeα​​)​

结论显然，证明略

引理 3 设 ppp 为质数，α≥β\alpha \geq \betaα≥β，则方程组

{x≡a1(modpα)x≡a2(modpβ)\begin{cases} x \equiv a_1 \pmod {p^\alpha}\\ x \equiv a_2 \pmod {p^\beta} \end{cases}{x≡a1​(modpα)x≡a2​(modpβ)​

的解就是方程 x≡a1(modpα)x \equiv a_1 \pmod {p^\alpha}x≡a1​(modpα) 的解，即在有解的条件下二者等价。

证明

若方程组有解，则 ∃k,l\exists k, l∃k,l 使得：

x=a1+kpα=a1+(kpα−β)pβ=a2+lpβ\begin{align*} x = a_1 + kp^\alpha &= a_1 + (kp^{\alpha-\beta})p^\beta\\ &= a_2 + lp^\beta \end{align*}x=a1​+kpα​=a1​+(kpα−β)pβ=a2​+lpβ​

即

a1≡a2(modp)a_1 \equiv a_2 \pmod pa1​≡a2​(modp)

故原方程组可写成：

{x≡a1(modpα)x≡a1(modpβ)\begin{cases} x \equiv a_1 \pmod {p^\alpha}\\ x \equiv a_1 \pmod {p^\beta} \end{cases}{x≡a1​(modpα)x≡a1​(modpβ)​

该方程组的解显然是 x≡a1(modpα)x \equiv a_1 \pmod {p^\alpha}x≡a1​(modpα) 的解，即二者等价。

利用以上三个引理，可以将原方程组转化为模数为素数乘方的方程组，若不存在矛盾的方程，则可用中国剩余定理求解。

方法二：两两合并法

由引理 1 的证明，若方程组有解，对前两个方程，可由扩展 Euclid 算法解得 p,qp, qp,q 使得 pm1−qm2=a1−a2pm_1 - qm_2 = a_1 - a_2pm1​−qm2​=a1​−a2​，则两个方程等价于

x≡pm1+a1(modlcm(m1,m2))x \equiv pm_1+a_1 \pmod {\mathrm{lcm}(m_1, m_2)}x≡pm1​+a1​(modlcm(m1​,m2​))

或

x≡qm2+a2(modlcm(m1,m2))x \equiv qm_2+a_2 \pmod {\mathrm{lcm}(m_1, m_2)}x≡qm2​+a2​(modlcm(m1​,m2​))

以此类推。
